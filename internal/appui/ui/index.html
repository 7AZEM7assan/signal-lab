Settings

Alert thresholds apply to the next batch stored; events already stored keep their alerts. Changing the queue or workers rebuilds the ingest engine: queued events are saved first, the live feed reconnects, and it is refused while a replay is running.

Delete all data

Removes every stored event and alert. Settings are kept. This cannot be undone; export first if you need the data.

About

Signal Lab simulates machine readings by default; no real hardware or plant is involved. You can also send readings (or your own data file) to a service of your own to see how it copes with overload, duplicates and bad data. It is a test tool, not a production system.
